# YVYTY `.github`

Organization profile and community configuration for [YVYTY](https://github.com/yvyty).

The profile page shown at <https://github.com/yvyty> is rendered from
[`profile/README.md`](profile/README.md). Its project showcase is generated from
the org's public repositories by [`scripts/sync-projects.mjs`](scripts/sync-projects.mjs),
run nightly by [`.github/workflows/sync-profile.yml`](.github/workflows/sync-profile.yml).

This repository holds no product code. See the individual project repositories.
